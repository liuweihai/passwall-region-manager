# luci-app-bypass-failover · v0.1.0 开发预览

**目标设备：小米 Mi Router 3G / OpenWrt 24.10.5 / 192.168.31.1**，不要安装到 192.168.31.2。这个子目录与旁路由上的 `luci-app-passwall-region-manager` 完全独立。

## 当前已有功能

- LuCI 菜单：服务 → 旁路由智能容灾
- 只读状态与日志、手动健康检查
- 强制直连、明确确认后切换自动模式
- IPv4 fwmark + 独立路由表，自动模式才设置引流
- 连续失败判定、连续恢复判定、冷却时间
- 自动模式失效时尝试清理引流规则，返回小米直连
- 可选 HTTPS Webhook，故障/恢复通知（服务端格式依赖通知服务提供方）

## 重要限制（未完成验证）

**这不是经过实机验证的成品，首版不要直接在全屋投入使用。**

- 健康检查仅探测 192.168.31.2 Ping 与 DNS 请求，**尚未检测真实 PassWall 代理出口**；DNS/Ping 正常不意味着代理服务正常。
- IPv6 未接管；当前仅针对 IPv4 的路由策略。
- 首版尚未验证相同 LAN 子网下的 fw4/nftables 回程与 SNAT、连接保持，且没有自动化实机故障注入结果。
- 默认 `direct`，安装后不会改动 DHCP、DNS、系统默认路由，不自动开启或启用服务。
- 切换可能中断现有连接，不保证游戏、视频通话或下载完全无感。
- Webhook 只支持基础 JSON `{ "text": "..." }`；不是所有通知平台都使用此格式。
- 路由器掉电后无法发送故障消息；小米主路由必须保持在线才能监测旁路由。

## 安装与使用

`install.sh` 是经 GitHub API 下载源码的安装器，需在小米 31.1 上执行。它不会自动启用服务，安装前应保留当前 SSH 与网页访问能力以及已备份的 /etc/config/network、dhcp、firewall。

页面菜单：**服务 → 旁路由智能容灾**。

配置文件：`/etc/config/bypass_failover`，默认保持 direct。可调整 `interval`、`fail_count`、`recover_count`、`hold_seconds`，新增 `option webhook 'https://...'` 配置通知地址。

当前阶段建议只使用页面的状态、日志和健康检查；**自动模式需在兼容性及单客户端引流验证后才开启**。

## 与另一个模块的边界

- **31.1**：本插件，旁路由失效时的 LAN 转发容灾。
- **31.2**：`luci-app-passwall-region-manager`，六国节点验证与日志。

二者不会相互替换，不共享 UCI 配置。
