## v0.3.0-beta6 · 只安装主路由（研发验证版本）
- 唯一安装位置：主路由（例如 192.168.31.1）。旁路由（例如 192.168.31.2）保留已有 PassWall，不安装任何新组件。
- 新增只读拓扑检查，检查 LAN、候选下一跳、策略路由表占用、规则优先级、内核转发与 ICMP redirect 配置，参考 shunt 的独立路由表及诊断思路；未复制 shunt 源码。
- 不更改 DHCP 网关/DNS、不开放 SOCKS5、不安装 socat、不修改旁路由。
- 由于之前真实客户端测试出现过断网，临时引流和全屋 auto 仍维持安全锁定。此版本主要用于无损审计，不能据此宣称联网、回程或容灾已通过。
- experimental 目录内历史旁路由研究源码不作为产品安装依赖，也不再打包发布。
- 完整功能仍需证明 PassWall 透明接管、国内直连回程及旁路由真实失效时的无损回退。

## 新手怎么用

1. 主路由安装插件；旁路由保持原来的 PassWall TCP 透明代理设置。
2. 在「服务 → 智能网络保护」填写旁路由 IPv4 地址，点击「一键检查」。检查只代表旁路由 Ping/DNS 可达，**不会修改转发规则**。
3. 「开机自动启动」可以独立选择；开启开机启动 **不等于** 开启全屋引流。
4. 单台设备的临时 TCP 引流测试目前属于 **高级设置**，最长约 60 秒，看门狗尝试自动清理，另有手动撤销入口。测试存在短暂断网风险，仅限可恢复的实验设备和维护窗口。
5. 全屋保护继续锁定：需要真实代理出口、回程、防环路及故障回退验证，不能手动修改 `forwarding_verified` 跳过验证。

## v0.3.0-beta5 变更

- 取消「必须先直连 Cloudflare 成功才能检测旁路由路径」这一错误前置条件。
- 新增 `path_reachable_unverified` / `path_unreachable` 等明确状态；成功只表示主路由发出的标记 TCP 请求可达，**不能说明客户端流量、代理出口或回程已成功**。
- 代理出口没有独立证据时仍保持 `health` 失败、禁止自动引流；默认仍为直连。

## v0.3.0-beta5 变更

- 新增临时测试的入口匹配包数与 SNAT 出口包数，便于区分策略命中和实际转发阶段。
- 临时测试开始约 12 秒后，如果已出现入口匹配包、但 SNAT 计数仍为零，自动提前撤销引流，不再一律等待 60 秒。
- 以上修复提高诊断和回退安全性，**尚不能证明 Mac 访问百度的问题已经解决**；在独立回程验证完成前，全屋保护仍锁定。
- 主路由 DHCP 保留 `3,主路由IP` 和 `6,主路由IP` 即可；插件不需要更改 DHCP 网关或 DNS。

## 已实现

- LuCI 新手页面，随 LuCI 主题继承基本控件样式；高级设置默认折叠；中文/英文提示。
- 主路由直连默认模式、旁路由基础 Ping/DNS 检查。
- 开机启动开关与网络保护开关相互独立。
- 单设备测试：匹配已识别 IP + MAC、只标记未占用的 TCP 流量、独立 nftables/策略路由表、回程 SNAT、匹配包计数。
- 临时测试最多约 60 秒、看门狗撤销、页面手动撤销、状态检查异常撤销和服务重新启动清理。
- 提供历史兼容的 HTTP/SOCKS5 代理出口检测，但 **临时透明 TCP 测试不再要求 SOCKS5**。
- GitHub Actions 进行 shell、LuCI JavaScript、ACL JSON 语法检查和 IPK 构建。

## 尚未通过验收 / 仍待开发

- 真实端到端代理出口证明（匹配包计数≠PassWall 代理成功）。
- 自动选择浏览器/设备并完成真实请求、回程及 ICMP Redirect 防环路验证。
- 实际旁路由断电、代理进程故障、恢复后自动回切的可靠性与抖动防护验收。
- DNS、UDP、IPv6 的完整容灾策略；不同网络拓扑和 fw4/offload 兼容。
- 自动解除全屋保护锁定以及完整一键验收报告。
- 断电、进程崩溃等场景无法保证不断网；TCP 会话可能重建。

## 安装包

GitHub Actions: `.github/workflows/build-bypass-failover.yml`。构建脚本：`bash luci-app-bypass-failover/build-ipk.sh`；预期产物：`dist/luci-app-bypass-failover_0.3.0-beta5_all.ipk`。**只有构建工作流成功时才说明包已生成，语法检查和构建成功也不代表实机容灾通过。**

插件应安装在 **支持 fw4/nftables 的主 OpenWrt 路由器**，不可和旁路由上的多国家节点管理器混装。IPv4 主路由 IP、旁路由 IP 均由用户填写或从本地配置读取，不写死任何家庭 LAN 地址。
